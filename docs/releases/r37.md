# 更新了一些东西

- 开放未来世界，沿用 Iris 原生地图、关卡和支线；补齐战场背景、正式音乐、香橼音效与机甲巨人表现。
- 接入 Aster 黑暗时代地图的 30 个主线、9 个支线位置，以及对应关卡、药水、迷雾、盗贼和大法师。
- 接入文艺大剧院与百步穿僵的实际玩法，包括道路、房屋保护、单株升级、狼的技能，以及箭种、库存和计分。
- 接入黑暗时代 12 种 Aster 植物及官方中文版胆小菇。中文版自创植物采用一阶基础属性、指定的二阶固有技能；路灯花保留 Aster 原有效果，不导入全局阶级系统。
- 原僵王关改为 15 波传送带，包含 13 种植物、13 种普通黑暗时代僵尸。僵王移植停止，已有原型保留在源码中，不接入安装包。
- 补充黑暗时代中文文案，保留用户优化的译文，当前中文覆盖表共 1,907 条。

# 修复了一些东西

- 修复黑暗时代入口、地图加载、夜色色调、卡槽图片、音乐及底部世界选择栏布局。
- 修复新增植物奖励的地图资源依赖，以及最终传送带首次奖励和世界出口的兼容配置。
- 补齐新增植物的原生名称与存档编号映射，修复普通进度进入地图时检查咖啡豆等未解锁奖励引发的闪退，保留原有植物编号。
- 机甲巨人充能、扫射、收招时停止行走，调整光束与灼痕同步，并接上结束音效。

# 尚未完善的细节

**！注：这是黑暗时代移植初版，动画、音效、布局与玩法细节仍待完善。尚未逐关完整验收，也不代表所有表现已经与 Aster 一致；后续将按实测反馈继续微调。**

- 游戏失去焦点后冻结的问题仍列为待办，本轮未修复。
- 点击图鉴后可能闪退，已按用户要求暂缓修复。
- 文艺大剧院的狼、百步穿僵的靶子保留在各自小游戏中，不混入普通传送带。
- 骑马僵尸及骑手仍替换为铁盔僵尸；未映射的旧关卡副本保留归档，不另造地图入口。

# 安装

- ARM32，包名 `com.pvz2unline.iris`。请使用相同签名覆盖安装，保留现有进度。
- APK 与安装复测信息以本次 Release 附件和下方验证记录为准。
